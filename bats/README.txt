MessengerSlayer launchers v4.1

Windows:
  double-click RUN_WINDOWS.bat

Linux:
  chmod +x ./bats/RUN_LINUX.sh
  ./bats/RUN_LINUX.sh

macOS:
  chmod +x ./bats/RUN_MACOS.command
  double-click RUN_MACOS.command in Finder
  or run ./bats/RUN_MACOS.command

Git commit/push on Windows:
  run COMMIT_AND_PUSH.bat from a Git clone
  branch: integration/cross-platform-launchers
